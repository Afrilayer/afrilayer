# Insurpass API

Insurance technology platform for Nigeria.

## Overview

Insurpass provides insurance technology APIs for Nigerian businesses, offering digital insurance solutions, policy management, and claims automation.

## Products

- Policy Issuance API - Create insurance policies
- Claims Management API - Process insurance claims
- Underwriting API - Risk assessment and pricing
- Digital Onboarding API - Streamline customer onboarding

## Authentication

Uses API Key authentication. Register at insurpass.com to get API credentials.

## Sandbox

Sandbox environment available for testing integrations.

## Coverage

Available in Nigeria.
