# OkHi API

Digital addressing and location API for Africa.

## Overview

OkHi solves the challenge of physical addresses in Africa through digital addressing and location APIs that provide precise geolocation and address verification.

## Products

- Address API - Create and manage digital addresses
- Verification API - Verify physical addresses
- Autocomplete API - Address suggestions and validation
- Location API - GPS coordinate handling

## Authentication

Uses API Key authentication. Contact OkHi for API access.

## Coverage
