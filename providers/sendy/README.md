# Sendy API

Logistics and delivery API for Africa.

## Overview

Sendy provides an API for businesses to streamline their logistics and delivery operations across East Africa, connecting to a network of verified transporters.

## Products

- Deliveries API - Schedule and track package deliveries
- Pricing API - Get real-time delivery pricing estimates
- Tracking API - Real-time package tracking updates

## Authentication

Uses API Key authentication. Register at sendy.co.ke to get API credentials.

## Sandbox

Sandbox environment available for testing integrations.

## Coverage

Available in Kenya, Uganda, and Tanzania.
