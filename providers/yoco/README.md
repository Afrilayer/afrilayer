# Yoco API

Card payments for South African businesses.

## Overview

Yoco provides payment solutions for South African businesses, including card readers, online payments, and POS systems with developer APIs.

## Products

- Payments API - Accept card payments online and in-person
- POS API - Point of sale integration
- QR Payments API - Generate and verify QR payment codes

## Authentication

Uses Bearer Token authentication. Register at dashboard.yoco.com to get API keys.

## Sandbox

Sandbox environment available for testing integrations.

## Coverage

Available in South Africa.
