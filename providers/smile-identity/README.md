# Smile ID API

## Overview

Biometric KYC — selfie liveness, document verification and AML screening. Identity verification platform for African markets.

## Key Features

- **Selfie Liveness**: Real-time selfie verification
- **Document Verification**: Check identity documents
- **AML Screening**: Anti-money laundering checks
- **Biometric Checks**: Fingerprint and facial recognition

## Authentication

Uses Bearer Token authentication. Include your token in the Authorization header.

```
Authorization: Bearer YOUR_TOKEN
```

## API Endpoints

- `/v1/id_verification` - Identity verification
- `/v1/document_verification` - Document check
- `/v1/liveness` - Selfie liveness
