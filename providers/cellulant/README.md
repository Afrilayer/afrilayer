# Cellulant API

Pan-African payments and merchant services platform.

## Overview

Cellulant is a leading African payments company providing merchant acquiring, payment aggregation, and value-added services across 12 African countries. Their API enables businesses to accept payments across multiple channels.

## Products

- **Card Payments**: Accept card payments across Africa
- **Mobile Money**: Integrate with mobile money wallets
- **Bank Transfers**: Enable direct bank transfers
- **Merchant Services**: Payment gateway and POS solutions
- **Multi-country Payouts**: Cross-border payment distribution

## Supported Countries

Kenya, Nigeria, Ghana, Tanzania, Uganda, Zambia, South Africa, Côte d'Ivoire, Senegal, Morocco, Egypt, Cameroon.

## Authentication

Uses API Key authentication. Include your key in the request headers.
