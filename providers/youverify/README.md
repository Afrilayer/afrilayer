## Overview

Youverify is an African identity verification and compliance platform that helps businesses automate Know Your Customer (KYC), Know Your Business (KYB), Anti-Money Laundering (AML), and fraud prevention workflows.

Its APIs enable organizations to verify identities, validate official documents, screen against global watchlists, perform business verification, and automate customer onboarding.

## Products

### Identity Verification API

Verify customer identities using trusted government data sources.

Supported verification methods include:

- BVN
- NIN
- Passport
- Driver's License
- Voter ID
- Face Match
- Liveness Detection

---

### KYB API

Verify businesses and organizations.

Features include:

- Business registration lookup
- Company verification
- Director verification
- Compliance checks

---

### AML API

Perform compliance checks against:

- Sanctions Lists
- PEP Lists
- Watchlists
- Adverse Media

---

### Document Verification API

Validate government-issued identity documents.

Supported capabilities include:

- OCR extraction
- Authenticity checks
- Face comparison

---

### Background Checks

Perform employment and compliance background verification.
