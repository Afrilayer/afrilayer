# Flutterwave API

## Overview

Flutterwave provides a unified payments API covering cards, mobile money, bank transfers and payouts across Africa. Accept payments, send payouts, and manage transactions from one integration.

## Key Features

- **Card Payments**: Accept debit and credit card payments from major providers
- **Mobile Money**: Integrate with mobile money wallets across Africa
- **Bank Transfers**: Enable direct bank transfers in multiple African countries
- **Payouts**: Send money to beneficiaries across Africa
- **Multi-currency Support**: Handle transactions in multiple currencies

## Authentication

Uses API Key authentication. Include your secret key in the Authorization header.

```
Authorization: Bearer YOUR_API_KEY
```

## API Endpoints

- `/v3/payments` - Payment initialization
- `/v3/transactions` - Transaction verification
- `/v3/transfers` - Money transfers
- `/v3/beneficiaries` - Beneficiary management
