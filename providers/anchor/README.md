# Anchor API

## Overview

Anchor provides a Banking-as-a-Service API that enables businesses to build and embed financial products for their customers, including accounts, payments, and savings.

## Key Features

- **Virtual accounts**: Create and manage virtual bank accounts
- **Savings wallets**: Build savings products with flexible rules
- **Payments**: Process payments across multiple channels
- **KYC automation**: Streamline customer verification
- **Card issuance**: Issue debit cards to customers

## Authentication

Uses Bearer Token authentication. Include your API key in the Authorization header.

```
Authorization: Bearer YOUR_API_KEY
```

## API Endpoints

- `/api/v1/accounts` - Account creation and management
- `/api/v1/wallets` - Savings wallet operations
- `/api/v1/payments` - Payment processing
- `/api/v1/customers` - Customer management
