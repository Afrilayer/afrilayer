# Lami API

Digital insurance platform for emerging markets.

## Overview

Lami provides a digital insurance infrastructure API that enables businesses to embed insurance products into their offerings across Africa, focusing on microinsurance and scalable coverage.

## Products

- Insurance API - Embed insurance products
- Policy Management API - Create and manage policies
- Claims API - Process insurance claims
- Risk Assessment API - Evaluate risk profiles

## Authentication

Uses Bearer Token authentication. Register at lami.africa to get API credentials.

## Sandbox

Sandbox environment available for testing integrations.

## Coverage

Available in Kenya, Nigeria, and Ghana.
