# Treepz API

Mobility and transportation platform for Africa.

## Overview

Treepz (formerly Treepz Mobility) provides APIs for corporate transportation, ride-hailing, and fleet management across African markets.

## Products

- Ride Booking API - Book and manage rides
- Fleet Management API - Vehicle and driver management
- Corporate Transport API - Enterprise transportation solutions
- Payment API - Handle ride payments

## Authentication

Uses API Key authentication. Register at treepz.com to get API credentials.

## Sandbox

Sandbox environment available for testing integrations.

## Coverage

Available in Nigeria, Ghana, and Kenya.
