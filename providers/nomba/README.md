# Nomba API  
  
## Overview  
  
Nomba provides business banking, payment collection, and financial infrastructure for businesses in Nigeria and beyond. Offers POS terminals, business accounts, and payment APIs for seamless transactions.  
  
## Products  
  
- **POS Payments**: Accept card payments via POS terminals  
- **Business Accounts**: Digital business banking accounts  
- **Payment Collection**: API for collecting payments from customers  
- **Transfers**: Send money to bank accounts  
  
## Authentication  
  
Uses API Key authentication. Include your API key in the Authorization header.  
  
\`\`\`  
Authorization: Bearer YOUR_API_KEY  
\`\`\`
