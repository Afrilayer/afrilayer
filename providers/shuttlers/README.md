# Shuttlers API

Corporate transport and mobility solutions for Nigeria.

## Overview

Shuttlers provides a corporate mobility API that enables businesses to offer shared transportation services to employees across Nigeria, reducing commute costs and improving employee benefits.

## Products

- Ride API - Book and manage employee shuttles
- Route API - Optimize transportation routes
- Fleet API - Manage vehicle fleet
- Tracking API - Real-time GPS tracking

## Authentication

Uses API Key authentication. Register at shuttlers.ng to get API credentials.

## Sandbox

Sandbox environment available for testing integrations.

## Coverage

Available in Nigeria.
