# Crop2Cash API

Agricultural supply chain and finance platform.

## Overview

Crop2Cash provides agricultural finance and supply chain APIs that connect farmers to financial services, input suppliers, and markets across Nigeria.

## Products

- Farm Finance API - Access agricultural financing
- Input Procurement API - Purchase farming inputs
- Market Access API - Connect to buyers and markets
- Data Collection API - Collect farm data and insights

## Authentication

Uses API Key authentication. Register at crop2cash.com to get API credentials.

## Sandbox

Sandbox environment available for testing integrations.

## Coverage

Available in Nigeria.
