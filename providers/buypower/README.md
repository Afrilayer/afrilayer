# BuyPower API  
  
## Overview  
  
BuyPower provides an API for purchasing electricity units and paying utility bills in Nigeria. Enables seamless bill payments for businesses and consumers.  
  
## Products  
  
- **Electricity Payment**: Purchase electricity units  
- **Utility Bills**: Pay various utility bills  
- **Bill Verification**: Verify bill status before payment  
- **Automated Top-up**: Schedule automatic bill payments  
  
## Authentication  
  
Uses API Key authentication.  
  
## Sandbox  
  
Sandbox environment is available for testing.
