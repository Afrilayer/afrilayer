# VALR API  
  
## Overview  
  
VALR is a cryptocurrency exchange and trading platform offering digital asset trading, custody, and API services to individuals and institutions in South Africa and across Africa.  
  
## Products  
  
- **Cryptocurrency Trading**: Buy and sell digital assets  
- **Digital Asset Custody**: Secure cryptocurrency storage  
- **API Trading**: Programmatic trading interface  
- **Market Data**: Real-time and historical price data  
- **Instant Swaps**: Quick cryptocurrency exchanges  
  
## Authentication  
  
Uses API Key authentication with HMAC signatures.  
  
## Sandbox  
  
Sandbox environment is available for testing.  
  
## Coverage  
  
- South Africa
