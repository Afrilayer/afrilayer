## Overview

VALR is one of Africa's largest cryptocurrency exchanges, offering secure digital asset trading for retail and institutional customers.

Its developer platform provides REST and WebSocket APIs for trading, market data, wallet management, and account operations.

## Authentication

Private endpoints require API Key authentication with HMAC request signing.

Example headers:

```http
X-VALR-API-KEY: YOUR_API_KEY
X-VALR-SIGNATURE: SIGNATURE
X-VALR-TIMESTAMP: TIMESTAMP
```
