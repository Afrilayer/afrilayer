# Nalo SMS API

## Overview

Bulk SMS and messaging API with delivery reports across West Africa. Send SMS via API to Ghanaian and Nigerian phone numbers.

## Key Features

- **Bulk SMS**: Send SMS to large groups
- **Delivery Reports**: Real-time delivery status
- **Messaging**: Two-way SMS support
- **Regional Coverage**: Ghana and Nigeria

## Authentication

Uses Bearer Token authentication. Include your token in the Authorization header.

```
Authorization: Bearer YOUR_TOKEN
```

## API Endpoints

- `/sms/v1/send` - Send SMS
- `/sms/v1/status` - Check delivery status
