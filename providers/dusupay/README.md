# DusuPay API  
  
## Overview  
  
DusuPay is a payment gateway enabling businesses to accept payments through multiple channels including cards, mobile money, and bank transfers in Nigeria and Ghana.  
  
## Products  
  
- **Card Payments**: Process card transactions  
- **Mobile Money**: Accept mobile money payments  
- **Bank Transfers**: Direct bank transfers  
- **Payouts**: Send money to beneficiaries  
  
## Authentication  
  
Uses API Key authentication.  
  
## Sandbox  
  
Sandbox environment is available for testing.  
  
## Coverage  
  
- Nigeria  
- Ghana
