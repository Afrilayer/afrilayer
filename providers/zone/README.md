# Zone API  
  
## Overview  
  
Zone provides payment infrastructure and API services enabling businesses to accept payments, make transfers, and manage financial operations in Nigeria and Kenya.  
  
## Products  
  
- **Card Payments**: Accept card payments from customers  
- **Bank Transfers**: Direct bank transfer capabilities  
- **Mobile Money**: Mobile money payment acceptance  
- **Payouts**: Send money to multiple recipients  
- **Virtual Accounts**: Generate virtual account numbers  
  
## Authentication  
  
Uses API Key authentication.  
  
## Sandbox  
  
Sandbox environment is available for testing.  
  
## Coverage  
  
- Nigeria  
- Kenya
