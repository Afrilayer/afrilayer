# Mono API

Open banking for African businesses.

## Overview

Mono provides open banking infrastructure that enables African businesses to access customer financial data and initiate payments through secure APIs.

## Products

- Payments API - Initiate payments from customer bank accounts
- Accounts API - Verify and access account information
- Transactions API - Access transaction history
- Income API - Verify income and employment status
- Identity API - Customer identity verification

## Authentication

Uses API Key authentication. Register at mono.co to get your API key.

## Sandbox

Sandbox environment available for testing with test bank accounts.

## Coverage

Available in Nigeria, Kenya, Ghana, and South Africa.
