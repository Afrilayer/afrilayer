# Prembly API

## Overview

Document verification, facial matching and AML checks for financial services. Identity verification platform tailored for African markets.

## Key Features

- **Document Verification**: Passport, ID card, and driver's license checks
- **Facial Matching**: Compare photos against documents
- **AML Checks**: Anti-money laundering screening
- **Identity Verification**: Comprehensive KYC

## Authentication

Uses API Key authentication. Include your key in the x-api-key header.

```
x-api-key: YOUR_API_KEY
```

## API Endpoints

- `/v1/verify` - Document verification
- `/v1/facial` - Facial matching
- `/v1/aml` - AML screening
