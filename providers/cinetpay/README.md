# CinetPay API  
  
## Overview  
  
CinetPay is a payment gateway offering mobile money, card payments, and airtime services across Francophone Africa.  
  
## Products  
  
- **Mobile Money**: Accept mobile money payments  
- **Card Payments**: Process card transactions  
- **Airtime**: Airtime purchase API  
- **Payouts**: Send money to customers  
  
## Authentication  
  
Uses API Key authentication. Include your API key in requests.  
  
## Sandbox  
  
Sandbox environment is available for testing.  
  
## Coverage  
  
- Cote d'Ivoire  
- Senegal  
- Cameroon
