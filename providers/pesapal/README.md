# Pesapal API

Payment gateway for East Africa.

## Overview

Pesapal provides a secure payment gateway for businesses in East Africa, enabling card payments, mobile money, and bank transfers through a unified API.

## Products

- Payments API - Process customer payments
- OAuth API - Authentication and authorization
- IPN API - Instant Payment Notifications

## Authentication

Uses OAuth 2.0. Register at pesapal.com to get consumer key and secret.

## Sandbox

Sandbox environment available at sandbox.pesapal.com for testing.

## Coverage

Available in Kenya, Uganda, Tanzania, and Rwanda.
