# SendByte API

Naira-priced transactional email API for Africa.

## Overview

SendByte is a developer-first transactional email API built for Africa, sending OTPs, receipts, and alerts with fixed Naira pricing (billed via Paystack or Flutterwave) and deliverability tuned for African networks. Infrastructure is hosted in-region with NDPR data residency built in. Built by Echospectra Technology Limited.

## Products

- Transactional Email API — send OTPs, receipts, and alerts
- Email Templates — MJML/Handlebars-based templating
- Deliverability Monitoring — inbox-placement and reputation tracking
- Suppression Lists — bounce/complaint suppression management

## Authentication

Uses API Key authentication.

## Sandbox

Sandbox mode available for testing integrations without sending live email.
