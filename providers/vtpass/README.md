# VTPass API

Bills payment API for airtime, data, electricity, and cable TV in Nigeria.

## Overview

VTPass provides a REST API for bills payment services in Nigeria, letting developers integrate airtime top-up, mobile data bundles, electricity (PHCN/DISCO) payments, cable TV subscriptions (DSTV/GOTV/Startimes), and education payments (WAEC) directly into their applications. Operated by Broadshift Technologies Limited.

## Products

- Airtime Top-up API — recharge airtime across Nigerian networks
- Data Bundle API — purchase mobile data bundles
- Electricity Payment API — pay PHCN/DISCO electricity bills
- Cable TV API — DSTV, GOTV, and Startimes subscriptions
- Education Payment API — WAEC result checker and registration pins
- International Airtime API — send airtime to phones outside Nigeria
