# Xend Finance API  
  
## Overview  
  
Xend Finance is a decentralized finance (DeFi) platform that provides yield farming and cryptocurrency services to credit unions and cooperatives in Nigeria and across Africa.  
  
## Products  
  
- **DeFi Yield Farming**: Earn yields on cryptocurrency investments  
- **Stablecoins**: Access to stablecoin investments  
- **Credit Union Integration**: Connect credit unions to DeFi  
- **Cooperative Savings**: Savings products for cooperatives  
- **Cryptocurrency Wallets**: Digital asset wallet services  
  
## Authentication  
  
Uses API Key authentication.  
  
## Sandbox  
  
Sandbox environment is available for testing.
