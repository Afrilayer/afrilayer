# Stitch API

Open finance infrastructure for Africa.

## Overview

Stitch provides open finance infrastructure enabling businesses to access financial data and initiate payments across African markets through a single API.

## Products

- Payments API - Initiate payments directly from customer bank accounts
- Accounts API - Verify and access account information
- Income API - Verify income and employment status
- Transactions API - Access transaction history
- Identity API - Verify customer identity

## Authentication

Uses OAuth 2.0 with PKCE flow. Applications must be registered to obtain client credentials.

## Sandbox

Sandbox environment available for testing with test bank accounts.

## Coverage

Available in South Africa, Nigeria, Kenya, and Ghana.
