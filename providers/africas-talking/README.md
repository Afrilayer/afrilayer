# Africa's Talking API

Communications API for Africa.

## Overview

Africa's Talking provides unified APIs for SMS, voice, airtime, payments, and USSD across African telecom networks.

## Products

- SMS Messaging API
- Voice API
- Airtime API  
- Payments API
- USSD API
- Card Payments API

## Authentication

Uses API Key authentication. Register at dashboard.africastalking.com to get credentials.

## Sandbox

Sandbox available for testing all products before going live.

## Coverage

Available in 12 African countries including Nigeria, Kenya, Ghana, Uganda, Tanzania, South Africa, Zambia, Malawi, Ethiopia, Rwanda, Sierra Leone, and Mozambique.
