# VerifyMe API

Nigeria's leading identity verification API.

## Overview

VerifyMe provides identity verification APIs for Nigerian businesses, enabling BVN, NIN, and document verification through simple REST endpoints.

## Products

- Identity Verification API - Verify Nigerian identities
- BVN Lookup API - Bank verification number checks
- NIN Verification API - National identity verification
- Document Verification API - Passport, driver's license validation
- Address Verification API - Physical address confirmation

## Authentication

Uses API Key authentication. Register at verifyme.ng to get API credentials.
