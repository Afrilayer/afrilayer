# Okra API

Open Finance infrastructure for African banks and fintechs.

## Overview

Okra provides Open Banking infrastructure that connects African financial institutions with third-party applications. Their API enables secure access to bank accounts, transactions, and income data across Nigeria and beyond.

## Products

- **Bank Linking**: Connect customer bank accounts securely
- **Account Verification**: Verify account ownership and status
- **Transaction Data**: Access transaction history and details
- **Income Data**: Retrieve income and employment information
- **Callbacks**: Real-time webhooks for data updates

## Supported Countries

Nigeria

## Authentication

Uses Bearer Token authentication. Include your API key in the Authorization header.

```
Authorization: Bearer YOUR_API_KEY
```
