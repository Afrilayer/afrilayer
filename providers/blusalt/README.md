# Blusalt API

## Overview

Blusalt provides digital identity and verification APIs for businesses to authenticate users and verify identities across African markets.

## Key Features

- **Identity verification**: Verify user identities
- **Document verification**: Validate official documents
- **Biometric checks**: Biometric authentication support
- **AML screening**: Anti-money laundering checks

## Authentication

Uses Bearer Token authentication. Include your API key in the Authorization header.

```
Authorization: Bearer YOUR_API_KEY
```

## API Endpoints

- `/api/v1/verify` - Identity verification
- `/api/v1/document` - Document verification
- `/api/v1/biometric` - Biometric checks
- `/api/v1/aml` - AML screening
