# Interswitch API

Nigeria's leading payment and commerce platform API.

## Overview

Interswitch provides APIs for payment processing, merchant services, and financial infrastructure across Nigeria and West Africa.

## Products

- Quickteller API - Bill payments and airtime
- Payment Gateway API - Card and bank payments
- Verve API - Card issuance and management
- Gift Cards API - Prepaid card solutions

## Authentication

Uses OAuth 2.0. Register at developer.interswitchgroup.com to get API credentials.

## Sandbox

Sandbox environment available for testing integrations.
