# Pargo API

Smart logistics and delivery solutions for South Africa.

## Overview

Pargo provides a smart logistics and delivery API that enables businesses to offer click-and-collect and home delivery services through a network of pickup points across South Africa.

## Products

- Deliveries API - Schedule and track home deliveries
- Pickup Points API - Access Pargo pickup point network
- Pricing API - Get real-time delivery rates
- Tracking API - Real-time package tracking

## Authentication

Uses API Key authentication. Register at pargo.co.za to get API credentials.

## Sandbox

Sandbox environment available for testing integrations.
